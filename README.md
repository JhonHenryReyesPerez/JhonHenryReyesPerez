## Proyectos destacados


### Synapse Support Analytics — Plataforma Inteligente de Soporte Técnico

Sistema de análisis y gestión de incidentes tecnológicos que integra inteligencia artificial mediante arquitectura RAG para ofrecer asistencia basada en una base de conocimiento verificada. Incorpora indicadores calculados mediante SQL, búsqueda vectorial con Qdrant y automatización de procesos mediante n8n, integrando sus componentes a través de una API REST desarrollada con Spring Boot.

- **Stack:** Java 21, Spring Boot, PostgreSQL, JavaScript, n8n, Qdrant, OpenRouter, Docker
- **Arquitectura:** API REST, arquitectura por capas, RAG
- **Repositorio:** [Synapse Support Analytics](https://github.com/JhonHenryReyesPerez/synapse-support-analytics)


### CampusDesk — Sistema de Gestión de Soporte Técnico

Aplicación web para gestionar incidencias tecnológicas, con autenticación JWT, control de acceso por roles, asignación de técnicos y seguimiento de tickets. Implementa una API REST con arquitectura por capas y persistencia mediante JPA.

- **Stack:** Java, Spring Boot, Spring Security, PostgreSQL, JavaScript
- **Repositorio:** [CampusDesk](https://github.com/JhonHenryReyesPerez/CAMPUSDESK)

### RapidExpress — Sistema de Gestión de Flotas y Rutas

Sistema backend para administrar operaciones logísticas, incluyendo vehículos, conductores, paquetes, rutas y mantenimientos. Incorpora validaciones de negocio, seguimiento de entregas, reportes y persistencia de datos mediante MySQL.

- **Stack:** Java, MySQL, Maven
- **Arquitectura:** MVC
- **Repositorio:** [RapidExpress](https://github.com/SebbsAL/RapidExpress)

### SmartCity Fix — Plataforma de Reportes Ciudadanos

Plataforma desarrollada durante un hackathon para reportar y gestionar incidentes urbanos. Integra mapas interactivos, automatización de procesos mediante n8n y servicios externos para gestionar reportes y notificaciones.

- **Stack:** JavaScript, Node.js, Leaflet.js, Docker, n8n, APIs externas
- **Repositorio:** [SmartCity Fix](https://github.com/SebbsAL/Proyecto-N8N)

### Sistema de Gestión de Coworking

Base de datos relacional para administrar clientes, membresías, reservas, facturación y control de accesos. Implementa reglas de negocio mediante más de 20 triggers y eventos programados.

- **Stack:** MySQL
- **Repositorio:** [Proyecto MySQL](https://github.com/SebbsAL/Proyecto-MySQL)
